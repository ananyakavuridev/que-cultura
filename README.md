# que-cultura

A bilingual digital magazine exploring Hispanic cinema, music, art, and popular culture.

**Live website:** https://que-cultura-theta.vercel.app/

## Overview

¡Qué Cultura! is an independent digital magazine created to explore the stories, films, music, and personalities that shape Hispanic culture. The website brings cultural content together in an editorial-style experience, with a focus on visual storytelling and accessibility in two languages.

The project combines web development and design with an exploration of Spanish-speaking cultures.

## Features

- **Hispanic cinema:** Explore films and personalities that have influenced Hispanic cinema.
- **Pop culture:** Discover music, art, dance, traditions, and other cultural expressions.
- **Personality quiz:** Answer questions to discover a Hispanic cultural personality that matches your interests.
- **Bilingual content:** Explore cultural topics through a two-language experience.
- **Editorial design:** A magazine-inspired layout designed around typography, imagery, and visual storytelling.

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

Clone the repository:

```bash
git clone https://github.com/ananyakavuridev/que-cultura.git
cd que-cultura
```

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL shown in your terminal to view the website.

## Project Structure

The application is organised around its frontend components, pages, styling, and supporting configuration. These work together to deliver the magazine's content and interactive features.

## Purpose

The aim of ¡Qué Cultura! is to make Hispanic popular culture approachable through a digital publication that combines research, design, and interactive experiences.

From *cine* (cinema) and *música* (music) to *arte* (art) and *cultura* (culture), the project celebrates the diversity of the Spanish-speaking world.
