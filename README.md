# ¡Qué Cultura!

An independent bilingual magazine exploring Hispanic cinema, music, art and popular culture. Built with React, TypeScript, TanStack Start, Vite and Tailwind CSS.

## Development

Requirements: Node.js and npm.

```sh
npm install
npm run dev
```

## Scripts

- `npm run dev` — start the local development server
- `npm run build` — build the production app
- `npm run test` — run tests
- `npm run lint` — run ESLint
